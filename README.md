# Chess Game

A TypeScript + React chess game starter built with Vite.

## Commands

```bash
npm install
npm run dev
```

Other useful commands:

- `npm run check` — type-check the project
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally

The chess rules engine is provided by [`chess.js`](https://github.com/jhlywa/chess.js). The initial UI renders the starting position and includes a reset action; move selection and interaction are ready to be added next.
